Click Copy signature below and paste it into your email settings. This one is set up for Abby Donovan - anyone else can paste it and type over the name, position, mobile and email with their own details.

Install in Outlook:
  1. Click Copy signature below.
  2. Outlook > Settings > Mail > Compose and reply.
  3. Create a new signature and paste (Cmd+V / Ctrl+V) into the signature box.
  4. Set it as the default for new messages and replies, then Save.
Gmail: Settings (gear) > See all settings > General > Signature > Create new > paste > Save.
